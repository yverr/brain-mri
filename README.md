# brain-mri

A machine learning project for classifying brain MRI images into four categories:

- Glioma
- Meningioma
- No Tumor
- Pituitary

## Current Progress

- [x] Dataset exploration
- [x] Image preprocessing
- [x] Training/validation/test split
- [x] CNN architecture
- [ ] Model training
- [ ] Model evaluation
- [ ] Data augmentation
- [ ] Transfer learning
- [ ] Grad-CAM visualization
- [ ] Streamlit demo

## Dataset

Brain Tumor MRI Dataset from Kaggle.

The dataset contains 7,200 MRI images across four classes.

## Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Purpose

This project is being developed for learning purposes to understand
computer vision and machine learning using medical images.

This is **not a medical diagnostic tool**.
